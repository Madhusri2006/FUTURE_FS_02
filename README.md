# Client Lead Management System

A simple web-based application to manage and track client leads.

## Features

- Add new leads
- View all leads
- Search leads
- Update lead status
- Delete leads
- Dashboard statistics
- Express.js backend API
- Persistent lead data using JSON

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Lead Status

- New
- Contacted
- Converted

## How to Run

1. Open the project in VS Code.
2. Open the backend folder in the terminal.
3. Run:

```bash
node server.js
